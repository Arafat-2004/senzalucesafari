# About page imagery

These files are the editable, non-team images used by the public About page:

- `kilimanjaro.jpg` — About hero background
- `story.jpg` — Our Story image
- `fleet.jpg` — Why Book With Us / vehicle image

To update the About page imagery, replace a file with another image using the
same filename and format. Keep the subject framed for the documented ratio:

- `kilimanjaro.jpg`: wide landscape, 16:9 or wider
- `story.jpg`: landscape, approximately 4:3
- `fleet.jpg`: portrait, approximately 4:5

Team portraits are not stored here. They are managed through the team records
and remain database-driven so they can be updated independently.
